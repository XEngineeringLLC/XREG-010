# The settings the Victron GX shows (Mark's list, 2026-10-27), as web-app keys.
# gx_app/gen_settings.py reads labels, types, ranges, options, tooltips and echoes from
# web_src/index.html and web_src/script.js, and writes gx_app/xregulator/bridge/settings_schema.json.
#
# One key per line, in screen order, under a "# section: Title" header.
#   "# group: Title"            sub-heading for the keys that follow (must be a heading in index.html);
#                               without it the key's enclosing <details> summary is used.
#   KEY hidden                  published for gating only, not drawn.
#   KEY disabledWhen=K:V        greyed while key K echoes V.
#                               A key inside one of the app's gate containers (.gate-batt-current, .gate-soc-src,
#                               .gate-extra-temp, #float-gated-fields) is greyed the same way without an option
#                               (GATES in gen_settings.py); every key such a gate reads must be listed, hidden if not shown.
#   KEY enabledWhen=EP.F:V      usable only while field F of polled endpoint EP is V.
#   KEY confirm=fn:NAME[@V]     ask first, with the string a script.js function returns (only when writing V);
#                               confirm=const:NAME takes a script.js string constant.
#   KEY buttons=ID,ID           a select drawn by buttons outside a form (values traced from their handlers).
#   table ID KEY ...            the whole form holding KEY, saved in one request like the app's Save button.
#                               confirmIfChanged=PREFIX  the form's submit-listener warning, when a PREFIX<n> cell moved
#                               readOnlyWhen=PREFIX:K:V  that column is locked and left out of the save while K is V
#                               validate=ascending:PREFIX  the app's validateLearningTable rule on that column
#                               capMode=K                Amps/kW columns (data-cap-col) follow select K, one derived
#   @widget source=/endpoint    a GX-drawn panel fed by a JSON endpoint the app polls; anchor=ID (its place in
#                               index.html: help text, table headings), strings=NAME,... (script.js string arrays).
# The GX-only Connection section (regulator link and address, Regulators list) is drawn by XregCfgConnection.qml.
